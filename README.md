# TheresaXVI Configs

Public, opt-in appearance examples. This repository contains no client source.

The initial example is generated by the production ClickGUI constructor and saveDefaultAppearance in an isolated native UI test, without reading any personal configuration. It changes only the default Duotone appearance.

The client reads index.json anonymously over HTTPS, verifies size, JSON, format compatibility and SHA-256, downloads to an independent local name and requires an explicit Load action. It never uploads automatically. Local settings are not overwritten by refreshing this directory.

Index format version: 1. Client visual compatibility: 12.
